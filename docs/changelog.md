# <i class="bi bi-clock-history"></i> 更新履歴

## v1.2.0 beta <span class="en">2026-10</span>

- サイドバーを「シーン／マテリアル／輪郭線／背景・エフェクト」の4パネルに再構成
- 輪郭線パネルを新設（役割別の選択、線レイヤー、線スタイルのプリセット、輪郭線の一覧、構成チェック）
- 目（Parallax Eye）と口（Manga Mouth）を追加
- Manga Tone Shader にノーマルマップ、筆のタッチ、透過、絵画風、水彩を追加
- 背景ワールド・エフェクト・空と雲・吹き出しを追加
- 地面のマテリアル Manga Toon Ground を追加（ライトごとの影・影だけ・テクスチャと凹凸・AO・端を消す）
- カメラに歪み補正、ライトにライトリンキングの一覧を追加
- 描き文字をテキストオブジェクトに変更（16 種のワープ、編集モードでのカーニング、ふつうの回転、カメラに紐づける／外す、旧データの変換ボタン）
- エフェクトの色をサイドバーで調整できるように。一覧の行を選ぶとオブジェクトも選択
- 輪郭線パネルにラインアートの線の色を追加
- Manga Tone Shader のキー・フィル・バックを枠で区切り、トーン → オフセット → 色 → トーンのマテリアル → 描画モード・不透明度の順に整理
- 絵画風の古いドライバーが残って値が勝手に変わる不具合を修正
- ライセンス認証を追加
- 対応バージョンを Blender 4.5 LTS 以上に変更
