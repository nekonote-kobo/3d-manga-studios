# <i class="bi bi-question-circle-fill"></i> よくある質問・サポート

??? question "ライセンスキーのメールが届きません。"
    迷惑メールフォルダをご確認ください。それでも見つからないときは、申請したアドレスに誤りがないか確かめたうえで、管理者にご連絡ください。存在しないドメインのアドレスでは申請できません。

??? question "PC を買い替えたらどうすればいいですか？"
    新しい PC で同じキーを入れて認証してください。台数の上限に達している場合は、管理者に古い PC の解除をご依頼ください。

??? question "ライセンスキーをほかの人と共有してもいいですか？"
    できません。キーはご購入された方専用です。

??? question "Cycles で使えますか？"
    使えません。シェーダー、背景、エフェクトはすべて EEVEE を前提に作っています。

??? question "輪郭線の「レイキャスト」が灰色で選べません。"
    レイキャストは Blender 5.1 以上の機能です。4.5 では内側の線に「接触・谷折り（AO）」をお使いください。構成付きプリセットも 4.5 では自動で AO に置き換わります。

??? question "背景を変えるとキャラクターの明るさが変わりませんか？"
    変わりません。背景ワールドはカメラに映るときだけ色を出し、照明や反射としては黒になる作りです。3灯の RGB ライトの読み取りにも影響しません。

??? question "Manga Tone Shader が真っ黒になります。"
    キャラクターがライトグループの「照らす対象」（ライトリンキング）に入っているかご確認ください。入っていないと、3灯のライトが当たりません。

??? question "マテリアルがピンクになりました。"
    GPU のシェーダー命令数の上限を超えた可能性があります。光沢・異方性・AO・水彩・絵画風などを全部同時にオンにしたときに起こることがあります。使わない項目をオフにしてください。

??? question "吹き出しがぼけて見えます。"
    カメラの被写界深度（DOF）を使っていると、カメラのすぐ前にある吹き出しもぼけます。吹き出しを使うコマでは DOF をオフにするか、吹き出しをデザインアプリで入れてください。

??? question "Python スクリプトの自動実行を許可する必要はありますか？"
    不要です。視線や画面基準のエフェクトなどのドライバーは、自動実行なしで動くシンプルな式だけで作っています。

??? question "1つのファイルに複数のコマを作れますか？"
    1ファイル＝1コマを前提にしています。カメラは1台、背景はシーンに1つです。別のコマは別のファイルで作ってください。
