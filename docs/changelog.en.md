# <i class="bi bi-clock-history"></i> Changelog

## v1.2.0 beta <span class="en">2026-10</span>

- Reorganized the Sidebar into four panels: Scene / Material / Outlines / Backgrounds & Effects
- New Outlines panel (pick by role, line layers, line style presets, Outline List, setup check)
- Added eyes (Parallax Eye) and mouths (Manga Mouth)
- Added Normal Map, Brush Strokes, Transparency, Painterly and Watercolor to Manga Tone Shader
- Added background Worlds, effects, sky and clouds, and speech balloons
- Added the ground material Manga Toon Ground (per-light shadows, Shadow Only, texture and bumps, AO, Fade Edges)
- Added Distortion Fix to the camera and a Light Linking list to the lights
- Sound Effect Text is now a text object (16 warp styles, kerning in Edit Mode, normal rotation, Link to Camera / Unlink from Camera, a button to convert old data)
- Effect colors can now be adjusted in the Sidebar. Selecting a row in the list also selects the object
- Added Line Art line color to the Outlines panel
- In Manga Tone Shader, Key, Fill and Back are now framed separately and ordered as tone → offset → color → tone material → blend mode and opacity
- Fixed a bug where old Painterly drivers stayed behind and changed values on their own
- Added license activation
- Supported versions changed to Blender 4.5 LTS or later

## v1.0.1

- Added focal length to the camera settings
- Fixed a bug where renaming a material disconnected its screentones
