# <i class="bi bi-flag-fill"></i> Getting Started

Here is how to get up and running with 3D Manga Studios.

<ol class="ms-steps" markdown>
<li markdown><div markdown>**Install the add-on**

Install the zip from Preferences and enable it. → [Installation](install.md)</div></li>
<li markdown><div markdown>**Activate your license**

Request a license key, then activate with the key you receive by email. → [License Activation](license.md)</div></li>
<li markdown><div markdown>**Open the Sidebar**

Press ++n++ in the 3D Viewport, open the "3D Manga Studios" tab, and click "Create 3D Manga Collection". → [Feature Guide](../guide/index.md)</div></li>
</ol>

## <i class="bi bi-pc-display"></i> Requirements

| Item | Details |
|---|---|
| Blender | 4.5 LTS or later (5.2 LTS recommended). Below 4.5, the add-on stops loading and shows the reason |
| Render engine | EEVEE only (Cycles is not supported) |
| Features in 5.1 and later | Raycast outlines (automatic overlap and crease lines) |
| UI language | Japanese and English (follows Blender's language setting) |
| Location | 3D Viewport › Sidebar › 3D Manga Studios |
| License | MIT (add-on). For assets, see the bundled License_JP / License_EN |
