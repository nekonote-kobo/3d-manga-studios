# <i class="bi bi-flag-fill"></i> はじめに

3D Manga Studios を使い始めるまでの流れです。

<ol class="ms-steps" markdown>
<li markdown><div markdown>**アドオンをインストールする**

zip をプリファレンスから入れて有効にします。 → [インストール](install.md)</div></li>
<li markdown><div markdown>**ライセンスを認証する**

ライセンスキーを申請し、メールで届いたキーで認証します。 → [ライセンス認証](license.md)</div></li>
<li markdown><div markdown>**サイドバーを開く**

3D ビューで ++n++ を押し、「3D Manga Studios」タブから「3D漫画コレクションを作成」を押します。 → [機能ガイド](../guide/index.md)</div></li>
</ol>

## <i class="bi bi-pc-display"></i> 動作環境

| 項目 | 内容 |
|---|---|
| Blender | 4.5 LTS 以上（推奨 5.2 LTS）。4.5 未満では読み込みを止めて理由を表示します |
| レンダーエンジン | EEVEE 専用（Cycles は非対応） |
| 5.1 以上で使える機能 | レイキャストの輪郭線（重なり線・折れ目線の自動描画） |
| 表示言語 | 日本語・英語（Blender の言語設定に従う） |
| 場所 | 3D ビューポート › サイドバー › 3D Manga Studios |
| ライセンス | MIT（アドオン）。アセットは同梱の License_JP / License_EN を参照 |
