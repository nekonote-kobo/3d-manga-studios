    Material Specs NEW

    Every 3D Manga Studios material goes into a material in the same simple form: one Node Group plus an output. This section shows what happens inside each one, and how it looks when you change the values shown in the Sidebar and properties, using images actually rendered in Blender.

    MTS · Manga Tone ShaderScreentone, shadows, gloss and more: the shading of the whole object Manga Tone FlatFlat screentones you drop into a color field (10 types) Manga Tone ShadedShaded tones whose density changes with the lights (9 types) MTE · Manga Toon EyeEyes with depth (iris, pupil, highlights) MTM · Manga Toon MouthThe mouth plane and the geometry inside the mouth MTB · Manga Toon BackgroundsThe "Sky" background World (art style, time of day, clouds) MTG · Manga Toon GroundShadows cast on the ground, texture, AO and edge fade MTFX · Manga Toon EffectsForeground and background effects such as focus lines and sparks MTSB · Manga Toon Speech BubblesSpeech balloons (normal, shout, thought, narration)

    How to read the comparison images

    Example: Gloss OpacityGloss › Opacity

    The five spheres show the value changing from left to right. Each value is written under the image. The yellow cell is the default value for that setting. Everything except the setting being changed stays at its default.

    Blend mode labels

    Label Meaning
    Over Laid on top (normal mix)
    Multiply Darkens the color below
    Add Adds brightness to the color below
    Screen Lightens as it layers
    Mask Makes everything outside the shape transparent
    Switch Switches based on a value such as the art style
    Adjust Adjusts the color of the whole image
    Fixed Not used for lighting (seen by the camera only)
